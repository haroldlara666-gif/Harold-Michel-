# Mi primera página web

Proyecto académico de introducción al desarrollo web y al control de versiones con Git y GitHub.

## Contenido
- `index.html`: página personal adaptable a móviles y computadoras.
- `.gitignore`: archivos que Git debe ignorar.

## Cómo abrir
Abre `index.html` directamente en un navegador o utiliza la extensión Live Server de Visual Studio Code.

## Tecnologías
HTML5 y CSS3.
